# Aspiland Repository Launch

Status: public launch note; non-canonical  
Launch date: 2026-07-16  
Launch mode: formal public repository launch

Aspiland has formally launched as a public experimental repository and historical archive.

The repository contains governance experiments, software prototypes, research, stories and preserved historical material. Its structure separates accepted decisions, proposals, active projects, public communication and archives so that old ambition is not mistaken for current authority.

> **A world you do not join through a form. You enter through a commit.**

## What the launch opens

People may:

- inspect the repository and bilingual website;
- read current and historical material;
- report problems and ask precise questions;
- propose small, reviewable and reversible contributions;
- improve documentation, research, software and proposals through the documented contribution paths.

## What the launch does not create

The launch does **not** create:

- a sovereign state or legal jurisdiction;
- citizenship, compulsory membership or automatic rank;
- an operating governed community;
- a production public service;
- legal, medical or financial authority;
- a guarantee that historical code, binaries or experiments are safe or supported;
- a blanket license to reuse repository material.

Public visibility is not the same as permission to reuse. Aspiland intentionally has no project-wide license at this stage.

## Launch controls

Before launch, the project completed or formally resolved the repository-launch gates for secret review, current-tree privacy cleanup, repository controls, recovery rehearsal, encrypted offsite backup, onboarding review and residual-risk acceptance.

The formal decision is recorded in `docs/decisions/2026-07-16-repository-launch-go.md`.

## Explore safely

Start with:

1. the root `README.md`;
2. `docs/current-status.md`;
3. `docs/repository-map.md`;
4. `docs/glossary.md`;
5. `CONTRIBUTING.md`;
6. `public/onboarding/first-commit-kit.md`.

Treat unclassified legacy material, generated artifacts and historical binaries as unsupported unless a current project document says otherwise.

Report suspected secrets or unnecessary personal data privately through `SECURITY.md`. Never paste an exposed value into a public issue.

## Separate future milestone

A community or governance launch remains a later and separate decision. It requires additional accepted controls for canon, authority, participation, fair process, privacy, accessibility, continuity and shared services.
