# Repository Preview trailer

Status: public production script; non-canonical  
Target length: 55–65 seconds  
Last reviewed: 2026-07-12

## Creative direction

A restrained transmission from an unfamiliar but inspectable world.

Use repository paths, commit history, document fragments, status labels and abstract orbital geometry. Avoid stock footage of governments, parliaments, passports, weapons, crowds pledging allegiance or territorial maps.

The film should feel ambitious and strange, while every factual claim remains traceable to the repository.

## Audio

- begin with a quiet low-frequency signal and sparse mechanical texture;
- introduce a soft pulse when repository layers separate;
- do not use national anthems, marching rhythm, military drums or triumphal fanfare;
- keep speech fully intelligible without music;
- provide captions and a version without audio-dependent information.

## Editing rules

- keep the full disclaimer on screen for at least four seconds;
- do not show private repository data, credentials, personal contact details or unreviewed legacy content;
- use only repository material cleared for public communication;
- label simulations and concepts rather than presenting them as deployed capabilities;
- provide captions in the language of each published version;
- include alt text or a written transcript wherever the platform supports it;
- retain an editable project file and identify the repository commit used as the factual source.
