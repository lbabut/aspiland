# Public

This directory contains material intentionally prepared for public communication.

Public communication is non-canonical unless a separate accepted process explicitly says otherwise. Public visibility does not create a blanket reuse license.

## Formal repository-launch package

- [`repository-launch-note.md`](repository-launch-note.md) — current public launch announcement and boundaries;
- [`brand/README.md`](brand/README.md) — positioning, voice, visual direction, naming and disclaimer rules;
- [`press/one-pager.md`](press/one-pager.md) — concise project introduction for readers, media and potential partners;
- [`onboarding/first-commit-kit.md`](onboarding/first-commit-kit.md) — plain-language path to a first bounded contribution;
- [`artifacts/README.md`](artifacts/README.md) — safe templates for First Commit records and other world artifacts;
- [`../site/`](../site/) — bilingual dependency-free website source.

The active public framing is:

> **Formally launched public repository — an inspectable experiment and historical archive.**

This means that the repository and its ideas may be inspected and improved. It is not a declaration of a sovereign state, legal jurisdiction, operating governed community or production public service.

## Historical Preview material

The earlier Repository Preview campaign, trailer and announcement drafts remain in the repository as historical communication material. They must not be used as the current status statement without an explicit historical label.

## Publication review

Before publication, content should be reviewed for:

- personal or sensitive information;
- secrets, credentials and private infrastructure details;
- licensing and ownership of text, code, artwork and other assets;
- misleading claims about experiments or capabilities;
- material that could enable harm;
- unclear distinction between fact, fiction, satire, history and proposal;
- accessibility, readable structure and translation source version;
- accidental implication of legal identity, financial value or governance authority.

Public availability does not make a document canonical or licensed for unrestricted reuse.

## Maintenance rule

When public material summarizes another repository source:

1. update the source record first;
2. retain a link to the source;
3. state the current status accurately;
4. update translations together;
5. preserve corrections in repository history.
