# Aspiland

Aspiland is a long-running digital-state, governance and artificial-life laboratory. The repository contains constitutional experiments, public records, software prototypes and historical material created across several phases of the project.

This repository is an experiment, not a sovereign state, production service or claim of extraordinary technical capability.

## Start here

- [`canon/`](canon/) — documents explicitly accepted as binding. A file is not canonical merely because it exists in the repository.
- [`rfc/`](rfc/) — proposals and decision records.
- [`protocols/`](protocols/) — procedures for amendments, consent, review and rollback.
- [`projects/`](projects/) — active experiments, including [`UNIVERSE / MERCY`](projects/universe-mercy/).
- [`archive/`](archive/) — preserved legacy and superseded material.
- [`public/`](public/) — material intentionally prepared for unrestricted publication.
- [`docs/repository-map.md`](docs/repository-map.md) — map of legacy and current areas.
- [`docs/glossary.md`](docs/glossary.md) — current terminology and interpretation of historical terms.
- [`docs/go-live-checklist.md`](docs/go-live-checklist.md) — readiness gates for repository and community launch.
- [`SECURITY.md`](SECURITY.md) — private reporting, exposed-secret response and security scope.

## Legacy areas

The original directories remain in place while they are reviewed and classified:

- `AspieLand_TheUnitedStatesOfMinds/`
- `AspieLanguage/`
- `Embassies/`
- `SharedAssets/`
- `users/`
- `PublicChat.txt`
- `muminki_world/`

Their presence preserves history. It does not automatically make every statement current, factual or binding.

## Current principles

1. Preserve history without confusing it with current policy.
2. Separate law, proposals, experiments, fiction and operational data.
3. Do not commit secrets, personal data or generated runtime state.
4. Make consequential changes reviewable and reversible.
5. Prefer small, documented changes over destructive reorganizations.

## Contributing

Read [`CONTRIBUTING.md`](CONTRIBUTING.md) before making changes. Governance changes begin as RFCs. Software changes should identify the project they affect and avoid committing generated files.

## Status

The repository is undergoing a gradual, non-destructive cleanup. Existing history is retained; unclear legacy material is documented before it is moved or removed.
