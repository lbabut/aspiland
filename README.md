# Aspiland

Aspiland is a long-running digital-state, governance and artificial-life laboratory. The repository contains constitutional experiments, public records, software prototypes and historical material created across several phases of the project.

This repository is an experiment, not a sovereign state, production service or claim of extraordinary technical capability.

## Repository Preview

Aspiland is currently in public **Repository Preview**: an inspectable prototype of a digital civilization, not a community or governance go-live.

> **A world you do not join through a form. You enter through a commit.**

Their presence preserves history. It does not automatically make every statement current, factual or binding.

## Current principles

1. Preserve history without confusing it with current policy.
2. Separate law, proposals, experiments, fiction and operational data.
3. Do not commit secrets, personal data or generated runtime state.
4. Make consequential changes reviewable and reversible.
5. Prefer small, documented changes over destructive reorganizations.

## Contributing

Read [`CONTRIBUTING.md`](CONTRIBUTING.md) before making changes. Governance changes begin as RFCs. Software changes should identify the project they affect and avoid committing generated files.

New readers can use the [`First Commit Kit`](public/onboarding/first-commit-kit.md) to choose a small, understandable and reversible first contribution.

## Status

The repository remains in **Repository Preview**. Current-tree privacy remediation, the temporary no-license decision, branch controls, secret scanning and recovery rehearsal are documented.

Formal repository go-live still waits for review of external stores outside the connected Drive scope, downloaded-copy verification of the encrypted offsite backup and a new dated GO / CONDITIONAL GO / NO-GO decision. A community or governance launch requires the additional controls in [`docs/go-live-checklist.md`](docs/go-live-checklist.md).
