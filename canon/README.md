# Canon

This directory is reserved for documents that are currently binding within Aspiland.

A file must not be treated as canonical merely because it exists in the repository. Canonical status requires:

1. a clearly identified proposal,
2. public review appropriate to the affected community,
3. an explicit acceptance record,
4. a version and effective date,
5. a defined amendment and rollback procedure.

Until the first canonical package is formally accepted, historical constitutional documents remain preserved in their existing locations and must be treated as legacy material rather than automatically binding law.
