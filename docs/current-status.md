# Current status

Last updated: 2026-07-16

Aspiland is in **Repository Preview**.

The repository and static website are public and inspectable. Repository Preview is a communication and exploration milestone, not a formal repository go-live, community launch or governance launch.

Completed repository-launch work includes current-tree privacy remediation, a documented temporary no-license position, branch and secret controls, a full-history secret review, recovery rehearsal, private offsite backup upload and an unfamiliar-reader onboarding review.

The remaining repository-launch gates are tracked in [`docs/go-live-checklist.md`](go-live-checklist.md).

## Safe current description

Aspiland is a public experimental repository and historical archive in Repository Preview, under active review and controlled cleanup.

## Descriptions to avoid for now

Do not currently describe Aspiland as:

- production-ready;
- formally launched or fully cleared for unrestricted reuse;
- a sovereign state or legal jurisdiction;
- a fully operating governed community;
- universally open source;
- a supported software platform;
- administered by an autonomous supreme AI.

## Current boundaries

- Historical and user-area material is not automatically approved for promotion, reuse or execution.
- Repository visibility does not grant a blanket license; the current position is no explicit project-wide license during Repository Preview.
- A merged proposal is not automatically canonical.
- Public experiments do not establish extraordinary technical claims.
- The encrypted offsite backup is uploaded privately, but downloaded-copy checksum verification remains pending.
- External stores outside the connected Google Drive scope, especially Azure DevOps and independent local or deployment copies, have not been fully reviewed through the available connectors.
- Formal go-live remains **NO-GO** until the remaining controls are completed or explicitly accepted through a new dated decision record.
