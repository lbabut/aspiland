# Requests for Comments

RFCs are numbered proposals and decision records.

## Status values

- `Proposed` — open for review.
- `Accepted` — approved with a decision record and effective date.
- `Rejected` — considered and not accepted.
- `Superseded` — replaced by a later RFC.
- `Withdrawn` — removed from consideration by its author.

Merging an RFC records repository history, but the document should explicitly state whether it was accepted and when it became effective.
