# Projects

This directory contains active or intentionally maintained experiments.

Each project should document:

- purpose and status,
- owner or maintainer,
- entry points,
- dependencies,
- persistent local data,
- network access,
- known limitations,
- safe run instructions,
- whether claims are factual, hypothetical or fictional.

Legacy experiments may remain elsewhere until they have been inventoried and migrated without losing history.

## Legacy and unclassified areas

Anything outside the table above is not automatically active or supported. Legacy code, binaries, generated state and user-area material require inventory, privacy review and safe run instructions before being presented as maintained.

A project becomes active only when this index identifies its status, operational owner, dependencies and support boundary.
