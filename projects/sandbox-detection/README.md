# Sandbox Detection

Status: Conceptual research project

## Purpose

Develop falsifiable tests for specific computational models of physical reality.

The project does **not** assume that the Universe is a simulation and does not treat coincidences, subjective experiences or unexplained events as evidence. It asks a narrower scientific question:

> Does nature exhibit reproducible signatures predicted by a particular computational architecture?

A negative result can rule out or constrain a model. A positive result would first indicate an anomaly requiring independent confirmation; it would not by itself prove that reality is simulated.

## Research rules

1. Specify the tested architecture before examining the result.
2. Publish thresholds, statistics and exclusion criteria in advance.
3. Separate discovery data from confirmation data.
4. Correct for detector exposure and known astrophysical biases.
5. Require independent replication using different instruments or datasets.
6. Compare the sandbox hypothesis against ordinary physical explanations.
7. Record negative results and model constraints.
8. Do not use dreams, déjà vu, coincidences or personal impressions as experimental data.

## Experiments

- [`SANDBOX-01 / Cubic Fingerprint`](experiments/SANDBOX-01-cubic-fingerprint.md) — search for rotational-symmetry violations compatible with a cubic spatial lattice.

## Planned follow-ups

- **SANDBOX-02 / Latency** — test energy-dependent photon propagation using distant transient sources.
- **SANDBOX-03 / Geometric Noise** — search for correlated position noise with colocated interferometers.

## Interpretation boundary

These experiments can test particular models of discreteness, preferred directions or modified propagation. No finite experiment can rule out every possible simulation, especially one designed to reproduce all observable physical laws exactly.
